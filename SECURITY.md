# Reporting security issues

Do not include provider credentials, dconf exports, personal source text or private translated content in public issues.

After the repository is published, use GitHub's private vulnerability reporting if the maintainer enables it. Otherwise contact the maintainer privately through a contact method they have explicitly published. No security inbox or response-time guarantee is established by this source snapshot.

Translation requests leave your computer and go to the configured provider. Provider API keys are stored in ordinary GNOME GSettings/dconf, not a dedicated secret store.
